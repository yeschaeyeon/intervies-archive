# 생기부 아카이브 (학생용)

빌드 없이 돌아가는 정적 사이트입니다. 모든 데이터는 사용자 기기 브라우저에만 저장되고 서버로 전송되지 않습니다.

## 배포 (GitHub Pages)
1. 이 폴더 전체를 저장소에 올립니다. (HTTPS 필수: 녹음과 암호화 기능이 HTTPS에서만 동작)
2. Settings → Pages → Branch: main / root 선택.
3. 아이폰은 Safari에서 "홈 화면에 추가".

## 글꼴 교체
css/style.css 맨 위의 @font-face 와 --font 변수만 바꾸면 됩니다.

## 구조
- js/crypto.js, store.js: AES-GCM 암호화, 복구 키, 백업(.saenggibu)/병합
- js/hl.js: 형광펜, 글 상자
- js/files.js: txt/docx/pdf 읽기, 생기부 PDF 초안 분류
- js/views/: 화면별 코드
- vendor/: JSZip, pdf.js (로컬 포함, 외부 통신 없음)

## 처음 사용 흐름
안내(내 기기에만 저장) → 생기부 PDF 업로드(자동 분류, 다운로드 방법 안내) → 비밀번호(메모 확인) → 복구 키 → 자료 탭에서 "AI로 한 번에 입력" 안내.

## 한 번에 입력
- AI로 한 번에 입력: intake.js 의 IMPORT_PROMPT(공개용)를 사용자 AI에 붙여 넣으면 `@@학년/@@과목/@@활동/@@원문/@@설명/@@보고서/@@질문` 코드를 돌려주고, 앱에 붙여 넣으면 자동 입력돼요.
- 파일 여러 개 한꺼번에: 파일마다 학년·과목·활동·넣을 칸을 고르는 탭.
- 예상질문 일괄 만들기의 비공개 프롬프트는 prompt-pack.html 로 암호화해 qprompt.js 에 교체해요.


## 폴더 구조
하위 폴더 없이 한 폴더에 모든 파일이 들어 있어요. 이 폴더째로 올리면 돼요. (진입 파일: index.html)

## 처음 설정 흐름 (v4)
안내 → 생기부 PDF → 비밀번호 → 복구 키 → 면접 준비 만들기(예상질문 / 면접 자료 생성 → 완료하면 아카이브 입장). 모의면접에는 "교수님" 탭(대학별 사진 3장)이 있고, 면접 중 사진이 크게 떠요.
